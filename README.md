# Gestor de publicaciones

Aplicación web hecha con HTML y JavaScript puro para la Guía de Laboratorio 04 del curso Desarrollo de Software I (UNSAAC). Usa la API de prueba JSONPlaceholder.

## Qué hace
- GET: lista las publicaciones de un usuario, con cantidad elegible (5, 10 o 20) y filtro por título.
- GET: al hacer clic en una publicación, muestra sus comentarios.
- POST: crea publicaciones (con validación) y comentarios, mostrando el código de estado y el id devuelto.
- `formulario-get.html`: formulario con method="get" leído con URLSearchParams.
